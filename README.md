# djtool-releases

This app contains tools rekordbox DJs can use to improve their workflow for a variety of tasks, such as set building and tracklist generating. 

# Download Instructions: 

1) Download the latest .exe file from the release section.
2) For windows users, a message will appear as seen below. This message does not mean the app is unsafe, rather it appears because the app is new and has not been widely downloaded by many users. Simply click "More info" and click "Run anyway."
