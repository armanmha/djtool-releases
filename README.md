# djtool-releases

This app contains tools rekordbox DJs can use to improve their workflow for a variety of tasks, such as set building and tracklist generating. 

# Download Instructions (Windows):

1) Download the latest .exe file from the release section.
2) A message will appear as seen below. This message does not mean the app is unsafe, rather it appears because the app is new and has not been widely downloaded by many users. Simply click "More info" and click "Run anyway."

# Download Instructions (macOS): 
**PLEASE NOTE THAT macOS currently is not supported.**
**Note: macOS file is currently not tested, so the app file may not run.**

1) Download the latest 'djtool-mac.zip' file under the releases section.
2) Unzip the folder, and run the file 'djtool.app.'
3) On first launch, macOS will warn it cannot be opened since djtool is not yet signed with an Apple Developer certificate.
4) Open System Settings, and navigate to Privacy & Security.
5) Scroll to the Security section, and you will see a message saying djtool was blocked.
6) Click "Open Anyway."
7) Enter Mac password if prompted.
8) Click open.
9) djtool will now launch.
